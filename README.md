# SMO&CO — комментаторская графика для OBS

Пульт позволяет показывать в трансляции составы команд, карточки игроков, таблицу Кубка Великого Новгорода, голосование, болельщиков, квиз и видео. Пульт и OBS работают **на одном компьютере**. Для локального запуска ngrok и отдельная установка Python не нужны.

В папке уже лежат подготовленные команды, составы, данные пульта и загруженные видео. Не удаляйте папку `quiz/data` — она нужна для сохранения данных.

## Что потребуется

- Компьютер с Windows или macOS, на котором установлена OBS Studio.
- **Docker Desktop** — программа, которая запускает приложение. Скачайте её с [официального сайта Docker](https://www.docker.com/products/docker-desktop/) и установите по инструкции установщика. Если Docker попросит установить или включить необходимые компоненты Windows, выполните указания Docker и при необходимости перезагрузите компьютер.
- Интернет при первом запуске: Docker скачает необходимые компоненты. Фотографии игроков, которых ещё нет в локальном кэше, также загружаются из интернета.
- Свободный локальный порт **18770**.

## Шаг 1. Скопируйте папку на компьютер с OBS

Скопируйте **всю папку проекта целиком** на компьютер с OBS или скачайте и распакуйте архив репозитория. В папке должны быть файлы `Dockerfile`, `compose.yaml`, `DOCKER-START.bat`, `DOCKER-START.command` и папка `quiz`.

Если передаёте проект через GitHub, сначала загрузите файлы репозитория вместе с `quiz/data`. В этой папке находятся вопросы, ответы, результаты и видео: в открытом репозитории они будут видны всем.

## Шаг 2. Установите и запустите Docker Desktop

1. Скачайте [Docker Desktop](https://www.docker.com/products/docker-desktop/) и установите его для своей системы.
2. Запустите Docker Desktop и дождитесь, пока он полностью запустится.
3. Оставьте Docker Desktop работающим на время трансляции.

При первом запуске Docker может скачивать компоненты несколько минут. Если компьютер попросит перезагрузку после установки, перезагрузите его, снова запустите Docker Desktop и дождитесь готовности.

## Шаг 3. Запустите пульт

**Windows:** дважды нажмите `DOCKER-START.bat` в папке проекта.

**macOS:** дважды нажмите `DOCKER-START.command` в папке проекта. Если macOS блокирует запуск, откройте файл через контекстное меню Finder → **Открыть**. При необходимости откройте «Терминал», перейдите в папку проекта и выполните:

```bash
sh DOCKER-START.command
```

Скрипт соберёт и запустит приложение. Первый запуск может занять несколько минут. Когда запуск завершится, пульт должен открыться в браузере. Если не открылся, вставьте в адресную строку:

**Пульт: [http://127.0.0.1:18770/control.html](http://127.0.0.1:18770/control.html)**

Не закрывайте Docker Desktop во время эфира. Окно терминала после успешного запуска можно закрыть: контейнер продолжит работать, пока работает Docker Desktop.

## Шаг 4. Добавьте графику в OBS

1. Запустите OBS Studio на том же компьютере и выберите сцену трансляции.
2. Внизу, в блоке **«Источники»**, нажмите **«+» → «Браузер»**.
3. Укажите имя, например `Графика комментатора`, и нажмите **ОК**.
4. В поле **URL** вставьте:

   ```text
   http://127.0.0.1:18770/overlay.html
   ```

5. Установите **Ширина: 1920**, **Высота: 1080**. Режим «Локальный файл» должен быть выключен. Нажмите **ОК**.
6. В списке источников расположите графику **выше видео** трансляции, чтобы её не перекрывали другие источники. При необходимости нажмите правой кнопкой по источнику → **Преобразовать → Уместить в экран**.
7. Оставьте пульт открытым в обычном браузере. В нём выберите нужные команды и нажмите кнопку показа — графика появится в OBS. Пока ничего не показано, источник остаётся прозрачным.

Один источник OBS используется для всех видов графики: составов, игроков, турнира, голосования, болельщиков, квиза и видео. **Адрес пульта заканчивается на `control.html`, адрес источника OBS — на `overlay.html`.**

## Как работать во время трансляции

- Вверху пульта выберите две команды и нажмите **«Выбрать команды»**.
- В разделе составов нажмите нужную команду. Игроки автоматически сменяются в графике, каждый — примерно четыре секунды; повторный показ начинает список заново. Кнопка скрытия убирает состав из эфира.
- Команды, игроков и логотипы редактируйте по ссылкам в верхней части пульта. После изменения состава или логотипа повторно выберите команды для матча.
- Результаты и очки настраиваются на отдельной странице Кубка. Сохраните таблицу там, затем покажите её кнопкой в пульте.
- Перед показом отдельного игрока или загруженного видео используйте предпросмотр в пульте.

## Как остановить и запустить снова

Остановить приложение можно в Docker Desktop или командой из папки проекта:

```bash
docker compose down
```

Данные в `quiz/data` при этом сохраняются. Для повторного запуска откройте соответствующий файл `DOCKER-START` или выполните в папке проекта `docker compose up -d`. Файлы `DOCKER-START` выполняют сборку при запуске, поэтому их можно использовать и после обновления приложения.

## Если что-то не работает

- **Пульт не открывается.** Убедитесь, что Docker Desktop запущен и команда `DOCKER-START` завершилась без ошибок. Проверьте адрес `http://127.0.0.1:18770/control.html` именно на компьютере с OBS.
- **Порт занят.** Закройте другое приложение, которое использует порт 18770, затем повторите запуск.
- **Сборка завершилась ошибкой.** Проверьте интернет и сообщения Docker. На Mac скрипт при ошибке сборки повторяет попытку без сохранённых учётных данных Docker для открытого образа.
- **В OBS ничего не видно.** Убедитесь, что в источнике указан `/overlay.html`, источник включён и находится выше видео. Затем нажмите кнопку показа в пульте. Если источник был открыт до запуска приложения или обновления, нажмите правой кнопкой по источнику → **Обновить**.
- **Не видно фото игрока.** Проверьте интернет и наличие фото у игрока. Если фото отсутствует или недоступно, показывается силуэт. Не все игроки имеют исходную фотографию.
- **Нет команд или результатов.** Проверьте, что на компьютер перенесена папка `quiz/data` из подготовленного комплекта. При необходимости загрузите составы через страницу «Игроки» из `import/players.json`.

Адрес `127.0.0.1` всегда относится к текущему компьютеру. На другом компьютере он не подключится к этому пульту: для локальной схемы пульт и OBS должны быть запущены вместе.
