# Автоматические повторы и нарезка для OBS

Скрипт `highlights.lua` сохраняет копию каждого нового повтора буфера и по кругу показывает видео из отдельной папки в выделенном источнике «Источник медиа». Уже идущий ролик он не переключает: новые видео попадают в очередь после завершения текущего. Исходники буфера не удаляются и не изменяются.

## Что понадобится

- OBS Studio 29 или новее. В OBS должен быть включён **Буфер повтора**.
- Отдельная существующая папка для копий, например `C:\SMO\Highlights`. Создайте её вручную. Не указывайте папку исходных записей OBS; лучше использовать другую папку.
- Свободное место на диске: каждый повтор сохраняется второй копией. Скрипт ничего автоматически не удаляет.
- Только один экземпляр скрипта и отдельный источник медиа, предназначенный для этой нарезки.

## Настройка на Windows

1. В OBS откройте **Настройки → Вывод → Буфер повтора**, включите его и задайте продолжительность **10 секунд**. В разделе записи выберите папку для исходных повторов. В **Горячие клавиши** назначьте «Сохранить буфер повтора». Примените настройки. В основном окне OBS нажмите **Запустить буфер повтора**.
2. Создайте отдельную сцену, например «Нарезка», и в ней добавьте **Источник медиа**, например «Нарезка SMO». В свойствах источника включите «Локальный файл», отключите «Повторять» и «Закрывать файл, когда неактивен». Можно выбрать любой небольшой тестовый видеофайл; скрипт будет подставлять другие файлы. Разместите источник в кадре и проверьте аудиомикшер. Не используйте этот источник для отдельного повтора или другого видео.
3. Откройте **Инструменты → Скрипты**, нажмите **+** и выберите `highlights.lua`. В настройках скрипта выберите **Папка для копий** и **Источник медиа для нарезки**. Если источника нет в списке, закройте и заново откройте окно скриптов после создания источника.
4. Оставьте буфер повтора запущенным. Нажмите назначенную горячую клавишу: OBS сначала сохранит исходный повтор, затем скрипт скопирует его в выбранную папку. Дождитесь окончания копирования. Сохраняйте столько повторов, сколько нужно.
5. Включите сцену «Нарезка» в эфире. Скрипт проверит папку, запустит первый подходящий файл и перейдёт к следующему по окончании; после последнего начнёт сначала. Новые видео подхватятся при следующем переключении, не прерывая текущий ролик. На Windows читаются также подходящие видео, помещённые в папку вручную. Порядок — по имени файла.

Смена источника/сцены и видимость: скрипт запускает нарезку, когда выбранный источник активен в основном выходе OBS. В студийном режиме обязательно проверьте работу при переводе сцены из предпросмотра в программу. Переход между сценами или отключение видимости источника также может повлиять на встроенное поведение источника медиа; проверьте сценарий заранее.

## Проверка до эфира

1. Запишите два коротких повтора, дождитесь копий в папке и воспроизведите их вручную в обычном видеоплеере.
2. В OBS выведите сцену «Нарезка», убедитесь, что оба ролика проигрываются по кругу и слышен звук при нужном уровне микшера.
3. Во время воспроизведения сохраните третий повтор. Текущий ролик должен закончиться без скачка; новый появится при следующем обходе. Проверьте качество, масштаб и звук.
4. Переключитесь на другую сцену и обратно. Проверьте, что нарезка снова идёт и исходные повторы остались в своей папке.

## Если не работает

- **Ничего не копируется:** буфер должен быть включён и запущен; нажмите именно горячую клавишу сохранения повтора, а не остановки буфера. Проверьте существование папки, разрешение на запись и свободное место.
- **Источник отсутствует в списке:** используйте именно источник типа «Источник медиа» и откройте окно скриптов заново. Не выбирайте VLC Video Source.
- **Ничего не воспроизводится:** проверьте, что источник видим в активной сцене программы, папка содержит завершённые поддерживаемые файлы (MP4, MKV, MOV, FLV, TS, WebM), и файл воспроизводится самим OBS. Скрипт не проверяет заранее, что конкретный кодек поддерживается. Не добавляйте неполные или повреждённые файлы.
- **Диагностика:** в окне «Скрипты» откройте журнал скрипта; сообщения начинаются с `[Highlights]`. Приложите текст ошибки. Также доступно **Справка → Файлы журнала** в OBS.
- На Windows чтение и запись файлов используют Unicode Windows API, но сетевые диски, ограничения доступа и особенности конкретной сборки OBS необходимо проверить на месте. Для надёжности можно использовать простые локальные папки, например `C:\SMO\Replay` и `C:\SMO\Highlights`.
- Если скрипт выгрузить/перезапустить во время копирования, незавершённая `.part` может остаться в папке; она не участвует в воспроизведении. Проверьте её вручную после остановки скрипта. Оригиналы сохраняются.

## macOS и Linux

Копирование и воспроизведение записанных этим скриптом повторов работают через файл `smo-highlights-index.txt` в папке нарезки. Не удаляйте его. В отличие от Windows, скрипт не перечисляет произвольные видео, скопированные в папку вручную. Проверка на целевой системе обязательна.

Остановка скрипта: удалите его из окна **Инструменты → Скрипты**. Это не удаляет копии или оригиналы; отдельно остановите источник медиа и при необходимости буфер повтора.
